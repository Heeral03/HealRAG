Fast Healthcare Interoperability Resources (FHIR) Overview: FHIR (pronounced 'fire') is a next-generation standards framework created by Health Level Seven International (HL7). It defines how healthcare information can be exchanged between different computer systems regardless of how it is stored locally. FHIR combines the best features of HL7 Version 2, HL7 Version 3, and CDA, while leveraging modern web standards such as RESTful HTTP APIs, JSON, XML, OAuth2, and OpenID Connect.
