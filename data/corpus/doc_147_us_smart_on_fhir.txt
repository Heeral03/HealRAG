SMART on FHIR (SMART App Launch Implementation Guide): The standard authorisation framework for apps that access FHIR data, built on OAuth 2.0 and OpenID Connect. Two launch flows: EHR launch, where an app is launched from inside an EHR session and receives context such as the patient and encounter; and standalone launch, where the app starts outside the EHR, for example a patient-facing app, and the user chooses a patient. Scopes limit access, in the syntax patient/Observation.read for a single patient's observations, user/Patient.rs for resources accessible to the user, and system scopes for backend services. Version 2 scopes use CRUDS letters (create, read, update, delete, search). Apps discover server endpoints at /.well-known/smart-configuration. Public client apps should use PKCE (Proof Key for Code Exchange), and confidential clients authenticate with asymmetric keys. SMART on FHIR is the authorisation layer required for certified patient access APIs under ONC and CMS rules.
